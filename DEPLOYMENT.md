# STRUCTURA AI - Production Deployment Guide

This guide details the steps to deploy the complete **STRUCTURA AI** platform (FastAPI Backend, React Frontend, and PostgreSQL Database) to cloud providers, with native support for **Render Blueprints**.

---

## 🚀 One-Click Cloud Deployment via Render Blueprint

STRUCTURA AI includes a production-ready `render.yaml` specification that automates provisioning and interconnecting all three services in one operation.

### Architecture Topology

```
                  ┌───────────────────────────────┐
                  │    React + Vite Static Site    │
                  │     (structura-frontend)      │
                  │   CDN Global Edge Caching     │
                  └───────────────┬───────────────┘
                                  │
                 HTTPS / WSS REST & Telemetry
                                  │
                                  ▼
                  ┌───────────────────────────────┐
                  │       FastAPI Web Service     │
                  │      (structura-backend)      │
                  │  Uvicorn + PyTorch + OpenCV   │
                  └───────────────┬───────────────┘
                                  │
                 SQLAlchemy 2.0 (psycopg connection)
                                  │
                                  ▼
                  ┌───────────────────────────────┐
                  │     Render PostgreSQL DB      │
                  │     (structura-postgres)      │
                  │   Database: structura_ai      │
                  └───────────────────────────────┘
```

### 1. Prerequisites
1. A GitHub account with access to the STRUCTURA AI repository:
   `https://github.com/iamsonakshi07/-STRUCTURA-AI`
2. A [Render account](https://render.com).

### 2. Deploy via Render Blueprint
1. Log in to your **Render Dashboard** (`https://dashboard.render.com`).
2. Click **New +** in the top navigation and select **Blueprint**.
3. Connect your GitHub account and select the **-STRUCTURA-AI** repository.
4. Render will detect `render.yaml` and display the blueprint resources:
   - **Database**: `structura-postgres` (PostgreSQL `structura_ai`)
   - **Backend Web Service**: `structura-backend` (Python 3.11, `./render_build.sh`, `uvicorn`)
   - **Frontend Static Site**: `structura-frontend` (Node.js, `npm run build`, `./dist`)
5. Click **Apply**.
6. Render will automatically:
   - Provision PostgreSQL `structura_ai`.
   - Run `render_build.sh` (installs backend dependencies, runs Alembic migrations to head, and seeds demo data).
   - Inject the internal database connection string into the backend's `DATABASE_URL`.
   - Generate a secure cryptographic `SECRET_KEY`.
   - Build the React production bundle with the backend host URL.
   - Deploy both services with health checks on `/health`.

## ⚙️ Environment Variables Reference

### Backend Web Service (`structura-backend`)

| Variable | Description | Default / Render Source |
| :--- | :--- | :--- |
| `DATABASE_URL` | PostgreSQL connection URI (`postgresql+psycopg://...`) | Injected from `structura-postgres` |
| `SECRET_KEY` | JWT signing secret key (min 32 chars) | Auto-generated by Render Blueprint |
| `ALGORITHM` | JWT hashing algorithm | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Token lifetime | `1440` (24 hours) |
| `BACKEND_CORS_ORIGINS` | Allowed frontend origins (comma-separated or JSON) | `https://structura-frontend.onrender.com,http://localhost:5173` |
| `DEMO_MODE` | Fallback simulation for ML when GPU is unavailable | `true` |
| `PYTHON_VERSION` | Target Python version | `3.11.10` |
| `PORT` | HTTP port for Uvicorn binding | Assigned dynamically by Render |

### Frontend Static Site (`structura-frontend`)

| Variable | Description | Default / Render Source |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | Deployed backend URL (e.g. `https://structura-backend.onrender.com`) | Injected from backend host |
| `VITE_WS_BASE_URL` | WebSocket telemetry URL (optional, auto-derived from API URL) | `wss://structura-backend.onrender.com/ws/alerts` |
| `VITE_STATIC_BASE_URL` | Static inspection uploads host | Same as `VITE_API_BASE_URL` |

## 🐳 Alternative: Local Docker Compose Deployment

To run the complete production-like stack locally using Docker:

```bash
# 1. Clone repository
git clone https://github.com/iamsonakshi07/-STRUCTURA-AI.git
cd -STRUCTURA-AI

# 2. Copy environment templates
cp .env.example .env
cp frontend/.env.example frontend/.env

# 3. Launch all containers (PostgreSQL, FastAPI Backend, React Frontend)
docker compose up --build -d

# 4. Check services status
docker compose ps
```

Services will be accessible at:
- **Frontend Dashboard**: `http://localhost:3000`
- **Backend API & Swagger Docs**: `http://localhost:8000/api/v1/docs`
- **Health Diagnostic Endpoint**: `http://localhost:8000/health`
- **PostgreSQL Database**: `localhost:5432` (`structura_ai`)

## 🛠️ Post-Deployment Verification Checklist

1. **Verify Backend Health**:
   Visit `https://structura-backend.onrender.com/health`. Expect:
   ```json
   {
     "success": true,
     "message": "System operational",
     "data": {
       "status": "healthy",
       "database": "connected"
     }
   }
   ```
2. **Verify Interactive API Docs**:
   Visit `https://structura-backend.onrender.com/api/v1/docs`.
3. **Verify Frontend Dashboard**:
   Open `https://structura-frontend.onrender.com`. The Critical Infrastructure Monitoring cards, 3D Digital Twin, Defect Detection, and Analytics dashboards should populate with live PostgreSQL records.
4. **Verify Diagnostics in Settings**:
   Navigate to the **Settings** view in the web UI. Click **Run Diagnostics**. Confirm that FastAPI core, PostgreSQL database, and ML modules show active status.
